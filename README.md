# Currículo Digital — Deivison Santana

Currículo profissional interativo, responsivo e otimizado para SEO. Disponível em Português e English com toggle de idioma.

## 🌐 Demo

- **GitHub Pages**: [deivisan.github.io/Curriculo-Deivison](https://deivisan.github.io/Curriculo-Deivison)
- **deivi.tech**: [deivi.tech/curriculo](https://deivi.tech/curriculo)

## ✨ Funcionalidades

- **Toggle PT-BR / EN** — alternância de idioma com persistência em localStorage
- **SEO otimizado** — meta tags, Open Graph, Twitter Cards, schema.org JSON-LD
- **Acessibilidade** — skip link, landmarks semânticos, lang dinâmico, contraste WCAG AA
- **Print-friendly** — estilos de impressão dedicados, botão de download PDF
- **Design responsivo** — mobile-first, adaptável a todos os dispositivos
- **Sem emojis** — layout limpo e profissional
- **Sem pretensão salarial** — foco na competência

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (custom properties, Grid, Flexbox)
- JavaScript vanilla (i18n)
- Font Awesome 6 (ícones)
- Google Fonts (Inter)
- Tailwind CSS CDN (utilitário)
